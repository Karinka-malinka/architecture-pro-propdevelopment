## Разделы для проверочного листа
Наиболее приоритетные разделы проверочного листа:

### 1. Управление доступом
Аудит механизмов управления доступом позволит найти источники проблем, связанные с аутенитификацией и авторизацией пользователей и партнеров.
Наблюдается ряд проблем, связанных с доступом к данным:
1. Нет ограничений на доступ к данным - как в межсервисном взаимодействии применяется ролевая система доступов
1. Некорректное отржаение персональных данных клиентов в приложении - оценить работу механизмов аутентификации и авторизации
1. Партнёр из одной управляющей компании может увидеть или изменить данные клиентов и жилищных комплексов, которые относятся к другой компании - установить политики безопасности для API партнеров, чтобы предотвратить несанкционированный доступ к данным

### 2. Безопасность данных
Аудит безоспасности данных позволит найти источники проблем, связанные с соблюдения требований законодательства РФ в области обработки персональных данных, наличием единых политик безопасности для API партнёров, возможными уязвимостями в API

### 3. Управление инцидентами
Важный раздел, который должен помочь компании оценить ее возможности по предотвращению инцидентов с утечкой данных.

### 4. Специфические аспекты - Управление потоками данных
Аудит управления потоками данных позволит найти и устранить источники проблем для развития направления обработки данных на базе BI-, ML- и AI-технологий.
